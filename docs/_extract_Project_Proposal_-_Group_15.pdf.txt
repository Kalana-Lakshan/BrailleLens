1.
 
Executive
 
Summary:
 
 
The
 
proposed
 
project
 
is
 
to
 
develop
 
an
 
AI-powered
 
Braille
 
learning
 
and
 
self-assessment
 
system
 
built
 
on
 
the
 
NUS
 
AiSee
 
smart
 
glasses.
 
Using
 
the
 
glasses'
 
camera,
 
it
 
detects
 
when
 
a
 
learner's
 
finger
 
touches
 
a
 
Braille
 
character,
 
identifies
 
it
 
with
 
a
 
trained
 
computer
 
vision
 
model,
 
and
 
supports
 
two
 
modes:
 
a
 
Learning
 
Mode
 
that
 
reads
 
the
 
character
 
aloud,
 
and
 
a
 
Testing
 
Mode
 
that
 
listens
 
to
 
the
 
learner's
 
spoken
 
response
 
and
 
gives
 
instant
 
feedback.
 
The
 
model
 
is
 
trained
 
on
 
a
 
public
 
Braille
 
dataset
 
and
 
fine-tuned
 
using
 
our
 
own
 
data
 
collected
 
through
 
the
 
glasses
 
under
 
real
 
reading
 
conditions.
 
The
 
expected
 
outcome
 
is
 
a
 
working
 
prototype
 
enabling
 
independent,
 
hands-free
 
Braille
 
practice
 
without
 
requiring
 
constant
 
instructor
 
supervision.
 
 
2.
 
Problem
 
Statement:
 
Braille
 
is
 
the
 
primary
 
reading
 
and
 
writing
 
system
 
for
 
people
 
with
 
visual
 
impairments,
 
but
 
learning
 
it
 
often
 
requires
 
continuous
 
guidance
 
from
 
trained
 
instructors
 
and
 
specialized
 
resources,
 
limiting
 
opportunities
 
for
 
independent
 
practice.
 
Existing
 
solutions
 
mainly
 
focus
 
on
 
Braille
 
recognition,
 
translation,
 
or
 
text-to-speech
 
conversion,
 
while
 
a
 
few
 
educational
 
systems
 
rely
 
on
 
dedicated
 
Braille
 
hardware.
 
However,
 
there
 
is
 
no
 
widely
 
adopted
 
smart
 
glasses-based
 
system
 
that
 
integrates
 
real-time
 
computer
 
vision,
 
interactive
 
learning,
 
and
 
voice-based
 
assessment
 
into
 
a
 
single
 
platform.
 
This
 
project
 
aims
 
to
 
develop
 
an
 
AI-powered
 
smart
 
glasses
 
system
 
that
 
recognizes
 
Braille
 
characters
 
in
 
real
 
time,
 
reads
 
them
 
aloud
 
in
 
Learning
 
Mode
,
 
and
 
evaluates
 
the
 
learner's
 
spoken
 
answers
 
in
 
Testing
 
Mode
,
 
enabling
 
accessible,
 
hands-free,
 
and
 
self-directed
 
Braille
 
learning.

The

The

to

response

feedback.
 
The
 
system
 
will
 
integrate
 
image
 
processing,
 
deep
 
learning,
 
speech
 
technologies,
 
and
 
model
 
evaluation
 
techniques.

The

annotation

class
 
balance

separation,
 
and
 
evaluation
 
on
 
unseen
 
samples.
